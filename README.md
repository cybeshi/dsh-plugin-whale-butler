# 鲸娘管家 · DSH 插件

“说人话”就能记的本地账本。

截一张图、说一句话，鲸鱼娘就能帮你把账记好。她还能帮你统计收支、生成离线图表。不用懂会计科目，也不用学记账——人能听懂的，她都懂。

> 本项目是社区维护的非官方插件，与深度求索公司及 DeepSeek 官方无关。
> 插件免费分发，不收费、不捆绑付费服务。

## 工具

| 工具 | 用途 |
|---|---|
| `whale_expense` | 记一笔日常支出（模型不用写借贷方向） |
| `whale_income` | 记一笔收入；红包券可传 `coupon=true` |
| `whale_record` | 通用记账（复杂单据、多分录） |
| `whale_cart` | 购物车：满减摊销、红包收入、多账户付款 |
| `whale_refund` | 退款，挂原单 |
| `whale_snap` | 截图入账（模型看图，存图和原文） |
| `whale_query` | 余额、月报、账户流水、库存、经营毛利、进价历史、年费、理财、债权、分期、待摊、类别 |
| `whale_chart` | 离线 HTML 图表 |
| `whale_account` | 加账户、改名/加别名、找账户、设投资账户、补期初 |
| `whale_category` | 查看/新增/改名/移动/删除/迁移支出或收入类别 |
| `whale_fix` | 改单/重分类，保留修改历史 |
| `whale_card` | 信用卡还款日、账单日、额度、年费政策、共享实体卡 |
| `whale_product` | 商品：新增、列出、查找 |
| `whale_inventory` | 进货、销售、客户退货、供应商退货、期初库存 |
| `whale_deposit` | 借记卡下活期/定期：存入、查看、到期、提前支取 |
| `whale_receivable` | 债权：借出、利率规则、计息、还款 |
| `whale_debt` | 债务：期初欠款、借入、利息、还款 |
| `whale_prepaid` | 待摊：房租/学费等，首期付款日、每月同日、自动摊销 |

## 安装

- 需要 **DSH 0.2.0 及以上**、**Node.js 20 及以上**。
- 纯 Host 插件，零依赖、零构建。

步骤：

1. 克隆或下载本仓库：

```bash
git clone https://github.com/cybeshi/dsh-plugin-whale-butler.git
```

2. 在 DSH 的插件管理中，从本地目录安装这个仓库；或者让助手把仓库目录作为 bundle 安装。
3. 确认安装、批准提示后，**新开一个会话**（插件按会话加载）。
4. 在新会话里问一句「看一下余额」，能正常返回账本余额就说明生效。

## 数据位置

默认写在当前工作区下的 `whale-butler`：

```
<工作区>\whale-butler\
```

一个工作区一本账；换工作区就是另一本账。账本是本地纯文件（JSONL + JSON），卸载插件不会删除。

也可以用环境变量强制指定账本：

```powershell
$env:WHALE_BUTLER_DATA = '<你的目录>\whale-butler'
```

## 隐私

截图解析由模型完成，图片会随对话发到模型服务；账本文件始终只在本机。`whale_snap` 只在给了本机路径时复制图片原件。
